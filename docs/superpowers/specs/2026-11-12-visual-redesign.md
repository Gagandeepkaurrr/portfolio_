# Portfolio visual redesign

User direction: make the existing React portfolio more striking, polished and attention-grabbing. Preserve every content fact and working CMS/API workflow. The user has authorized the ongoing project and pushes; this is a presentation update rather than a new product.

Chosen direction: midnight-green hero and header, luminous citron accents, warm ivory reading sections and restrained lilac artwork. Use oversized Instrument Serif typography, a text-first hero with sculptural GK monogram placeholder, cinematic project panels, a prominent community milestone, refined skills/education and a bold contact ending. Keep actual image/PDF placeholders honest; no fabricated screenshots or portrait.

Implement a scoped public theme in public.css so the owner editor keeps its existing readable controls. PublicShell owns the theme class. Preserve SSR-visible content, reduced-motion support, keyboard controls and contrast; use short entrance/hover feedback and no perpetual animation, scroll hijacking or cursor replacement.

Acceptance: inspect desktop/mobile screenshots, run existing unit/types/build gates and real-stack browser acceptance including axe and320/360/768/1440 widths. Check actual owner preview also receives the public theme. Push the verified change to the existing repository.
