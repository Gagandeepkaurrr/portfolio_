# Portfolio architecture

The supplied project brief in `docs/project-brief.txt` is the product specification. The user requested implementation of that brief. Ordinary engineering choices are made here without additional approval gates. Work remains local; no public deployment, purchases, or external messages are part of this implementation.

React 19 with React Router framework mode renders one no-store public snapshot obtained from FastAPI. Vite supplies the development server and production bundling. Server loaders preserve public HTML, live metadata, sitemap, redirect aliases and HTTP 404 responses; a shared owner layout keeps editor state across client navigation. FastAPI alone owns PostgreSQL content, owner sessions, private media and contact storage. Browser requests use the same origin at `/api/v1`. Local origin is `http://localhost:3000`; API listens privately at `http://127.0.0.1:8100`.

Vite proxies API calls during development. A streaming React Router resource route supports the standalone Node server; production nginx sends API requests directly to FastAPI behind one TLS origin. On Vercel, the React Router preset packages the server-rendered frontend, while an external rewrite routes `/api/v1` directly to Render. That rewrite must be configured for the actual API hostname before deployment so media uploads bypass frontend functions. `API_INTERNAL_URL` remains server-only runtime configuration. Per-document CSP nonces apply to rendered HTML and hydration; owner pages are noindex and only the owner preview may frame the site.

One typed JSONB draft, revision preconditions, and immutable release snapshots preserve editorial isolation. Publication locks draft then state then media. Public projection removes hidden items and phone values, resolves media to authorized URLs, and never exposes storage keys. Session and CSRF values stay out of persistent browser storage. Uploads use a private filesystem volume.

Design: A Personal Journal of Building. Instrument Serif and Manrope, warm ivory #F5F1E8, deep teal #153E3B, sage #E4EBE4 and copper #A65F42. Portrait remains the intentional GK placeholder until the owner uploads a real image. Project artwork is clearly labeled and does not pretend to be a screenshot.

Alternatives considered: a static portfolio cannot fulfill the owner publishing/inbox requirements; a single JavaScript backend conflicts with the requested FastAPI boundary. A client-only frontend would lose the existing server-rendered public content and HTTP status behavior, so the React migration uses React Router framework mode. React Router 7.18.5 is pinned for compatibility with the Vercel adapter. JavaScript dependencies are locked with pnpm; Python uses uv on 3.12. Node and PostgreSQL versions are recorded in the toolchain configuration, lockfiles and verification results.

Optional SMTP is disabled unless explicitly configured; stored messages are reported as received, never delivered emails. S3 is an extension point, not an implemented storage backend. No portrait, project screenshots, or project-specific repository URLs have been supplied. The supplied real résumé is imported through the validated PDF path, outside Git.
